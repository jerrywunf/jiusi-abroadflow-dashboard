# 玖肆留学学生管理后台

基于 Next.js 14、TypeScript、App Router 与 Tailwind CSS 的留学咨询 SaaS MVP。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:3000。

生产构建：

```bash
npm run build
npm start
```

## 已实现

- 响应式左侧导航与移动端抽屉
- 学生、申请、录取、待办概览卡片
- 学生列表与申请进度展示
- 实时关键词搜索与状态筛选
- 新增学生弹窗及本地数据更新
- 空搜索结果与基础无障碍标签

当前使用演示数据，组件中的数据结构可直接替换为 API / 数据库查询结果。
